# Third-party software notices

LightningCAD-AI uses independent open-source projects as dependencies. Their source code is not copied into this repository; packages are installed from their normal distributions.

| Project | Role | Upstream |
|---|---|---|
| OpenCV | Image processing and computer vision | https://github.com/opencv/opencv |
| RapidOCR | Local OCR | https://github.com/RapidAI/RapidOCR |
| ONNX Runtime | CPU inference engine | https://github.com/microsoft/onnxruntime |
| ezdxf | DXF creation and validation | https://github.com/mozman/ezdxf |
| NumPy | Numerical computation | https://github.com/numpy/numpy |
| Pillow | Image display and conversion | https://github.com/python-pillow/Pillow |
| PyInstaller | Windows application packaging | https://github.com/pyinstaller/pyinstaller |

Each dependency retains its own upstream license and copyright notices. Before redistributing a compiled package, review the license files and notices included with the exact dependency versions used by the build.
