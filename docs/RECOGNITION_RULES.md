# 防雷草图识别规则

本文档是识别类别的语义依据。图像算法只能提出候选，不能绕过人工确认。

## 图元分类

| 类别 | 用户确认的含义 | 输出要求 |
|---|---|---|
| 测点 | 黑色实心三角形，旁边有字母/数字 | 三角形中心为定位点，编号单独保存 |
| 说明引线 | 带箭头或弯钩的细线 | 归入注释层，不是引下线 |
| 引下线 | 固定图例中的引下线符号 | 必须与说明引线区分 |
| 尺寸标注 | 尺寸线、尺寸界线和距离文字 | 不得当成建筑结构线路 |
| 标高 | 标高符号及其数值 | 独立于测点和普通文字 |
| 建筑结构 | 连续线条构成建筑平面边界 | 建筑轮廓与内部结构线分层 |
| 明装接闪带 | 固定图例中的带 X 线路 | X 标记只能作为辅助特征 |
| 弧线 | 明显弯曲的线条 | 拟合圆弧或保留自由曲线 |

## 关键消歧

建筑结构线和明装接闪带都可能带有 X 标记。不能仅凭 X 形笔迹分类，必须结合闭合轮廓、端点连接、线条位置、相邻符号和人工复核。

尺寸文字中的小数点、单位和数值必须核对。程序不能把 OCR 读出的数字直接当成现场实测值。

## 几何约束

- 近水平线可作为水平候选。
- 近垂直线可作为垂直候选。
- 直线交角接近 90 度时优先正交约束。
- 明显非直角结构保留原始角度。
- 明显弧线不能强制拉直。
- 未完成比例标定时，CAD 坐标为像素坐标。
