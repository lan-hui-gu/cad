# 防雷草图识别、简化与标记规则

本软件采用“识别原始图元 → 几何简化 → 人工语义标记 → Python 重新绘图”的流程。任何自动识别结果都只是候选，不会直接作为工程图输出。

## 一、图元语义

| 类别 | 用户确认的含义 | 输出要求 |
|---|---|---|
| 测点 | 黑色实心三角形，旁边有字母/数字 | 人工点选定位，生成三角测点符号和编号 |
| 说明引线 | 带箭头或弯钩的细线 | 归入注释引线层，不是引下线 |
| 引下线 | 固定图例中的引下线符号或实际引下线路径 | 与说明引线分开标记 |
| 尺寸标注 | 尺寸线、尺寸界线和距离文字 | 线段与人工确认的 OCR 文字分开管理 |
| 标高 | 标高符号及其数值 | 独立点位标记和文字确认 |
| 建筑结构 | 连续线条构成建筑平面边界及内部结构 | 建筑结构独立图层 |
| 明装接闪带 | 固定图例中的明装接闪带线路 | 与建筑结构分层 |
| 暗装接闪带 | 固定图例中的暗装接闪带线路 | 与建筑结构分层 |
| 弧线 | 明显弯曲的线条 | 保留曲线候选，人工确认后以多段线近似绘制 |

## 二、简化规则

- 对 Hough 原始线段按方向、法向偏移和端点间距进行共线聚类。
- 合并同一直线上的碎片，减少同一笔迹被重复识别的情况。
- 对接近水平或垂直的线段进行有限正交约束。
- 明显斜线不强制改成直角。
- 弧线独立保留，不参与直线合并。
- 简化阶段不推断“建筑结构/接闪带/引线”等工程语义。

## 三、人工标记规则

- 在线段列表或图像上选择简化线段，再指定工程类别。
- 曲线在曲线候选列表中单独选择和标记。
- 点位通过图上点击添加，可修改编号、删除或重新定位。
- OCR 文字默认不进入 CAD；双击校正并确认后才输出。
- “完成标记”是 DXF 输出的前置条件。
- 未标记或明确排除的图元不会写入 DXF。

## 四、工程图生成规则

DXF 由 Python ezdxf 根据人工确认的语义模型重新绘制，而不是把原图轮廓直接描摹到 CAD。线路、弧线、点位符号和确认文字分别进入独立图层。

没有可靠尺寸标定时，DXF 使用像素坐标，不代表现场实际毫米尺寸。所有尺寸、测点和线路仍须由检测人员依据现场记录复核。

## 五、关键消歧

建筑结构线和明装接闪带都可能带有 X 标记。不能仅凭 X 形笔迹分类，必须结合闭合轮廓、端点连接、线条位置、相邻符号和人工复核。
