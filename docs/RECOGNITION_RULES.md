# 防雷草图识别、简化与标记规则

本软件采用“识别原始图元 → 几何简化 → 人工语义标记 → Python 重新绘图”的流程。任何自动识别结果都只是候选，不会直接作为工程图输出。

## 一、图元语义

自动转绘阶段优先保持图形几何忠实，不在证据不足时推断工程语义。

| 类别 | 自动处理方式 | CAD 输出 |
|---|---|---|
| 建筑/线路直线 | 从简化线段直接转绘 | SIMPLIFIED_GEOMETRY |
| 明显弧线 | 保留曲线候选点列 | ARC |
| 黑色或彩色三角形 | 合并重叠候选并保留三角形轮廓 | SIMPLIFIED_SYMBOL |
| 圆形符号 | 保留圆心和半径 | SIMPLIFIED_SYMBOL |
| OCR 文字 | 保留识别框位置及文字候选 | SIMPLIFIED_TEXT |
| 尺寸线和尺寸文字 | 作为简化图几何及文字直接转绘；仅在关联可信时估算比例 | SIMPLIFIED_GEOMETRY / SIMPLIFIED_TEXT |

高级人工标记模式仍支持将建筑结构、明装/暗装接闪带、引下线、说明引线、尺寸线、测点、接闪杆、标高、接地点等映射到语义图层；该模式不是自动绘图的前置步骤。

## 二、简化规则

- 先识别主要闭合轮廓，建立主图区域及适度尺寸标注留白范围，优先剔除远离主图的页眉、页脚和杂散笔迹。
- 对主图区域内的 Hough 线段按方向、法向偏移和端点间距进行共线聚类。
- 合并同一直线上的碎片，减少同一笔迹被重复识别的情况。
- 对接近水平或垂直的线段进行有限正交约束。
- 明显斜线不强制改成直角。
- 弧线独立保留，不参与直线合并。
- 在真实交点处分段并重建拓扑节点，尽量保留 X 形交叉和 T 形连接。
- 未检测到可靠主轮廓时，不执行区域裁剪，保留全部简化候选。

## 三、自动转绘规则

- 白底简化预览与 CAD 导出共用同一份自动绘图模型。
- 预览和 CAD 使用相同的线段端点、曲线点列、符号顶点、圆心/半径和 OCR 文字位置。
- CAD 导出不重新识别原始照片，也不从 PNG 预览图反推坐标。
- 默认不要求用户逐条标记线段或输入每根线的起点、终点。
- 未分类几何统一进入 SIMPLIFIED_GEOMETRY 图层；自动绘图只复现图形，不推断其属于建筑结构、接闪带还是引下线。
- 用户仍可使用高级人工标记路径，生成语义分层图纸。

## 四、比例和审核边界

- OCR 尺寸文字与候选尺寸线关联成功时，尝试估算 mm/px；多组比例冲突时退回像素单位。
- 单一尺寸估算标记为低置信度；任何自动比例都不能替代现场实测标定。
- OCR 文字和符号仍可能误识别，简化图的几何质量决定 CAD 转绘质量。
- 自动 CAD 只复现简化图，不判断防雷系统电气连接可靠性、规范符合性或检测结论。
- 正式检测成果仍需按检测业务要求进行必要复核。

## 五、关键消歧

建筑结构线和明装接闪带都可能带有 X 标记。不能仅凭 X 形笔迹分类，必须结合闭合轮廓、端点连接、线条位置、相邻符号和人工复核。
